# Universal Simple Role-Playing (USR) for Foundry VTT

![Foundry v14](https://img.shields.io/badge/foundry-v14-green)

This project is an implementation of the **Universal Simple Role-Playing (USR)** system for Foundry Virtual Tabletop. It aims to be minimal, mirroring the simplicity of the USR system itself.

## Compatibility

- **Foundry VTT**: Compatible with v12 and v14.

## Features

- **DataModels**: Utilizes modern Foundry VTT DataModel definitions for robust data handling.
- **Minimalist Design**: Focused on core mechanics including character generation, combat, and dice rolling.
- **Custom Sheets**: Actor and item sheets built with Handlebars.
