# Character Generation & Advancement

### Experience (XP)

- **Rolling for XP:** When using a trait/specialization, the character may earn an XP check. If the roll was not a critical, the character "pays" 1 XP or uses a "Free Roll" earned from usage.
- **Trait Increase:** Needs 5 dots. Roll 2D10; total must be $> (\text{Value} \times 2 + 6)$.
- **Specialization Increase:** Needs 3 dots. Roll 2D10; total must be $> (\text{Value} \times 3 + 10)$.
